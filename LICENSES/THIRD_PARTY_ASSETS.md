# Third-party code and assets

Every art asset and sound in Dino Park Tycoon is generated procedurally in this repository's code
(dinosaurs, visitors, scenery, UI icons, sound effects, music). No third-party models, textures,
images or audio files are used.

| Package | Used for | License | Commercial use |
|---|---|---|---|
| [three](https://github.com/mrdoob/three.js) | 3D rendering | MIT | Yes |
| [@fontsource/fredoka](https://fontsource.org/fonts/fredoka) (Fredoka font) | UI typeface | SIL Open Font License 1.1 | Yes (font may not be sold on its own) |

Development-only tools (not shipped): TypeScript (Apache-2.0), Vite (MIT), Vitest (MIT),
playwright-core (Apache-2.0).

Before adding any new third-party asset, confirm its license permits commercial use in a paid/ad-supported
mobile game and add a row here.
